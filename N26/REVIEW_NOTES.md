# N26 Review Notes

Running log of judgment calls made while building N26 gang files from screenshots, for manual review/correction. Each entry: what was assumed, and why. Newest entries at the bottom of each section.

**Standing rule (corrected 2026-08-12):** every Pet-type fighter attaches to every other fighter in the gang, the same way Cawdor's Sheen Bird does — regardless of whether the rulebook gives it its own priced card. Delaque and Escher were both built wrong at first (pets as standalone Fighter-role roster entries) and have since been fixed; `build-gang-template`'s SKILL.md now states this as the rule going forward.

**Standing rule (corrected 2026-08-13, from user review of Cawdor):** a zero `Points` value must be `<real>0.0</real>`, never bare `0` — confirmed as what the Quartermaster app itself writes. Swept and fixed across every file (`N26.qmsystem`, all six gang files) — see the `git diff` from this pass if the exact fixed lines matter. Restriction lists belong in `Prerequisite`, never crammed into the item's `Name` in parentheses (`exterminator (autogun, shotgun, chainaxe and eviscerator only)` → `Name: exterminator`, tag `autogun/shotgun/chainaxe/eviscerator, Redemptionist`). Ammo-type variants always get `Multiple: true` plus a parent-weapon reference in `Prerequisite`, even brand-new ones — Escher's `shotgun acid ammo` was missing `Multiple` and got fixed to match. All three now documented in `build-gang-template`.

**Standing rules (added 2026-08-15, from user review of Cawdor/Delaque/Escher):** `Upper Limit` only on Leaders; a mount that grants its own weapon(s) becomes a per-fighter `Mount` key instead of a plain catalogue purchase (a mount that's just a subtype/movement grant stays a plain catalogue item, updated in place); starting skills/named special rules/fixed equipment that appear on a fighter's card are now captured instead of skipped; Brutes (and any unit whose card says it "may not purchase or be equipped with additional weapons or wargear") lose their `Magic Items` purchase list and their pet `Attached Units`, gaining fixed `Equipment` instead; every gang's Stash needs a `Gang Equipment` allowance; a gang's own name gets title-cased where it appears in an item name. All now documented in `build-gang-template`. Applied to Goliath, Orlock, and Van Saar this pass — Cawdor/Delaque/Escher are the user's own manual edits and weren't touched, see the judgment calls below for a few things noticed in passing there.

## N26.qmsystem (master catalogue)

- **Carapace Armour, Servo-Harness split by tier.** Source gives one name with two credit/TP tiers (Light/Heavy, Partial/Full). Split into two catalogue entries named `<item> <tier>` (`carapace armour light` / `carapace armour heavy`, `servo-harness partial` / `servo-harness full`), lowercase, no other fields. Confirmed pattern by user, reused throughout.
- **Weapon accessory restrictions folded into Prerequisite.** `focusing crystal`, `hotshot las pack` → `TP 1, las weapons only`; `suspensors` → `TP 0, weapons marked with * only`. The restriction text is appended verbatim (lowercased) after the TP value, comma-separated, in the single Prerequisite string — not modeled as a separate field.
- **`dirt bike` backfilled with `Prerequisite: [TP 0]`.** It predated the TP-tracking convention (had no Prerequisite at all) and was corrected once a source image gave its TP value.
- **TP-strip rule:** when copying/reusing an entry's Prerequisite elsewhere, strip only a `TP N` segment; keep any other comma-separated segment (e.g. `sawn-off shotgun` stays, `grenade launcher, TP 1` → `grenade launcher`). Established after an initial over-strip mistake.

Treated the corrected table as authoritative even where it overrode the original hand-authored Word-Keeper example (Combat was Primary in the file, table says Secondary).
- **Cawdor Close Combat reference page (filled in 2026-08-13):** filled Stats/Special Rules for `chain glaive*`, `eviscerator*`, `cleaver`, `frag lance*`, `krak lance*`, `stun lance*`. The three Cawdor polearms (`cawdor polearm/autogun*`, `.../blunderbuss with grape & purgation rounds*`, `.../flamer*`) are dual-profile weapons — melee polearm base plus a bolted-on ranged attachment — so each got a `Points: 0.0` sub-entry for its ranged component (`cawdor polearm/autogun* autogun`; the blunderbuss got *two* sub-entries, `... grape rounds` and `... purgation rounds`), same split pattern as the combi-weapons.
- **Lances only model their "primed" profile.** Frag/krak/stun lance each have a stronger "primed" (pre-charge) stat line and a weaker "spent" one on the reference page — spent is a battlefield state change, not a separate purchase, so only primed was captured.
- **Naming discrepancy, not fixed:** the reference page calls this weapon "Shock lance*", but the priced equipment list (and our existing catalogue entry) calls it "stun lance*". Assumed same weapon, book inconsistency — pulled its stats from the "Shock lance" reference row but kept the name as `stun lance*` to match the price list. Worth checking against the actual rulebook if this matters.
- **`Heavy club` skipped**, same reasoning as the earlier twin-linked heavy stubber skip: no independent price on the priced list (`Creds: -`), only relevant as Stig-Shambler's own starting weapon (already skipped, see above). Not in the catalogue.
- **Noticed but not touched (2026-08-15, this is your file to manage):** Stig-Shambler's `Equipment` now has `twin-linked heavy stubber` as a swap option with `Points: 0.0` — the original card text says this swap costs `+10 credits`, so this looks like it may have been missed when setting the price rather than intentional. Flagging both in case they're just not gotten to yet.
- **Personal Equipment / Mounts reference prose checked, no changes needed**: `bomb delivery rats`, `book of the redemption`, `cult icon`, `pyromantic mantle`, `ridge walker` are all already correct as bare Name/Points/Prerequisite entries — Personal Equipment and Mounts items don't carry Stats in this schema, so their rule text (Prime Bomb Rat, Words of Wrath, Group Activation re-roll, Blaze wargear, Mounted/Agile subtype) stays uncaptured by design, consistent with every other gang.
