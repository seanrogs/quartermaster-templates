# quartermaster-templates
Public repo for Quartermaster game systems and faction templates

## Website

templates.quartermaster.app is served from this repo by GitHub Pages. Each page (`index.html`, `HH.html`, `WHFB.html` and so on) is plain HTML: add templates inside the `<div id="content">` cards as before. The header, footer and `style.css` match [quartermaster.app](https://github.com/seanrogs/quartermaster-site), so keep them in sync with that site's `_layouts/default.html` and `assets/css/site.css`.
